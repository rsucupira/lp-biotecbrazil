# Landing Page — BiotecBrazil

Nova proposta de landing page estática para a BiotecBrazil, preparada para publicação no GitHub Pages.

## O que esta versão inclui

- Posicionamento mais claro para cursos, assessoria e empresas
- Layout responsivo para celular, tablet e desktop
- Cursos em formato de lista de interesse, sem datas antigas
- Formulário que cria uma mensagem pronta no WhatsApp
- Links para e-mail, redes sociais e páginas atuais dos cursos
- SEO básico, Open Graph, favicon e acessibilidade
- Animações leves sem dependências de frameworks

## Arquivos

- `index.html`: conteúdo e estrutura da página
- `styles.css`: identidade visual e responsividade
- `script.js`: menu, animações e integração com WhatsApp
- `assets/favicon.svg`: ícone do navegador
- `assets/social-card.svg`: imagem de compartilhamento

## Publicação no GitHub Pages

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve.

A página ficará disponível em:

`https://rsucupira.github.io/lp-biotecbrazil/`

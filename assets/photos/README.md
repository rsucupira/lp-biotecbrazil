# Fotografias da landing page

## Fotografia da coordenação científica

Envie a fotografia autorizada com o nome exato:

`elidamar.webp`

A landing page procura automaticamente o arquivo em:

`assets/photos/elidamar.webp`

Quando encontra a imagem, substitui o bloco com as iniciais `EN`. Se a imagem não estiver disponível, o layout mantém o placeholder atual.

### Especificação recomendada

- orientação vertical;
- proporção aproximada de 4:5;
- resolução mínima de 960 × 1.200 px;
- formato WebP;
- tamanho preferencial inferior a 500 KB;
- fundo simples e iluminação uniforme;
- autorização para uso institucional e comercial.
